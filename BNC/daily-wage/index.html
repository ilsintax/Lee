BNC 월 급여 처리

엑셀 파일 하나를 올리면 엑셀 파일 하나(상용직 · 일용직 · 확인필요 탭)를 만듭니다. 근무내역(1~31일) 탭에 있는 사람은 일용직(일자별 시간 + 과세급여·4대보험·세금), 없는 사람은 상용직(급여대장 열, 일자 없음)으로 나눕니다. 두 탭 모두 맨 앞에 순번이 붙습니다. 헤더 줄·빈 행은 자동으로 찾고, 고친 설정은 이 브라우저에 저장되어 다음 달에도 그대로 쓰입니다. 파일은 이 컴퓨터의 브라우저 안에서만 처리됩니다.

2탭 확인

탭 이름은 보지 않습니다. 1~31일 열이 있는 탭을 근무내역으로, 근무내역과 같은 사람이 있으면서 4대보험·세금 열이 가장 잘 맞는 탭을 급여 탭으로 고릅니다. 나머지 탭은 쓰지 않습니다.

근무내역 탭에 있는 사람 = 일용직, 없는 사람 = 상용직으로 나눕니다.

파일 1개 · 상용직 / 일용직 / 확인필요 탭

3일용직 가져올 항목

일용직 탭 양식: 성명 · 주민번호 · 1~31일 · 근무일수 · 총시간 · 아래 항목 · 확인사항. 자동으로 찾은 열입니다. 틀린 것만 바꾸세요. 노란 칸은 열을 찾지 못한 항목입니다.

결과 열 이름가져올 탭원본 열결과 첫 사람 값

검증 기준 (근무내역의 원래 합계 열)

1~31일 칸으로 직접 센 근무일수·시간을 이 열과 비교해서, 다르면 확인필요에 올립니다.

4일용직 미리보기

근무내역 탭(1~31일)이 없어 일용직 탭은 만들지 않습니다. 모든 직원이 상용직으로 들어갑니다.

3상용직 열 정리

상용직 탭 양식: 급여대장 열을 원본 순서대로 (일자 없음) + 맨 아래 합계. 열 이름은 제목 줄 중 맨 아래 줄을 씁니다.

기본으로 사번 · 성명 · 주민번호와 원본 제목의 지급내역 · 공제내역 묶음 아래 열만 들어갑니다. 그중 이번 달 값이 비어 있거나 0만 있는 열은 빠집니다. 다른 열이 필요하면 체크하세요. 새로 생긴 지급항목은 자동으로 들어가고 새 항목 표시가 붙습니다. 정보 열은 글자 그대로, 금액 열은 숫자로 저장하며 빈칸·문자(예: 가입제외)는 0으로 바꿉니다. 여러 열을 하나로 더하려면 "합치기"에 체크하고 아래 버튼을 누르세요.
