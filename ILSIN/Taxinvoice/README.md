# 세금계산서 일괄 발급 편집기

단일 HTML 기반 도구입니다.

## 현재 구현 내용

- 엑셀 복사/붙여넣기와 파일 업로드
- 제목 행 선택 후 `코드 / 거래처명 / 잔액 / 사업자번호`만 인식
- 사업자번호가 없는 행 자동 제외
- 잔액 자동 `* -1` 처리 및 더블클릭 수정
- `기장료 / 조정료 / 기타 / 혼합` 분류
- `기타` 직접 내용 입력
- 혼합 분류 합계 검증
- 분류 기준 JS 파일 저장 / 불러오기
- 불러온 기준으로 기억 기장료 채움 및 혼합 초안 생성
- 양식 엑셀 파일 기반 다운로드
- 출력 파일명: `yy.mm월 매출세금계산서(간편양식).xlsx`
